== Context

The Nix-mirror retirement campaign (`standards#102`) revealed that ~270 repositories carry a `guix.scm` (or `manifest.scm`) that is a **scaffold stub** rather than a functional package manifest. These stubs typically contain:

*   Template placeholders: `{{PROJECT_NAME}}`, `{{AUTHOR}}`
*   Empty input lists: `(inputs (list))`
*   Broken source fields: `(source #f)` or TODOs

This "scaffold-leak debt" prevented the retirement of the corresponding `flake.nix` files because the Guix side provided no real alternative.

== Remediation Strategy

For each repository in the list:

1.  **Hydrate:** Convert the stub into a real, functional Guix manifest that provides the same environment as the current `flake.nix`.
2.  **Verify:** Test the manifest with `guix shell`.
3.  **Retire Mirror:** Once the Guix side is functional, delete `flake.nix` and `flake.lock` per the original `standards#102` gate.
4.  **Alternatively — Purge:** If the repository is truly "stray" or the Guix manifest is not desired, delete the `guix.scm` stub entirely to clear the debt.
