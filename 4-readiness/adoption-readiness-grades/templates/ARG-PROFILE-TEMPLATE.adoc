== About this profile

This profile applies the *ARG v1.0* baseline to {LANGUAGE_NAME} and
records the current honest grade, the evidence supporting it, the
language-specific tightening obligations, and the path to the next
grade. Per ARG §1.1, profiles may *tighten* the baseline but never
*loosen* it.

ARG = {GRADE}. The full chain of axes for this language:

* ARG: {GRADE}
* TRG: {TRG_GRADE}
* FRG: {FRG_GRADE}
* CRG: {CRG_GRADE} (worst-of any released component)
* RSR: {RSR_LEVEL}

Cross-axis rule: ARG ≤ TRG holds (currently TRG = {TRG_GRADE}, ARG = {GRADE}).
