==== Key Implementation Details (2026-03-29)

*Reification (AST → RtValue):* - Complete coverage: DataExpr (14
variants), ControlExpr (17 variants), ControlStmt (15 variants),
TopLevelDecl (14 variants) - Plus: Pattern, BranchArm, GivenClause,
GivenItem, Handler, LocaleExpr, BinOp, PredOp - All nodes become
`+RtValue::Record+` with `+__kind+` discriminant — pure Data
(Harvard-safe)

*Reflection (RtValue → AST):* - Complete inverse of reification with
structured error handling - Returns `+Result<_, MetaError>+` for
malformed records

*Meta-Circular Eval Loop:* - Reifies each declaration to Data - Fires
MetaHook callbacks (before_step / after_step) - Reflects back to AST and
evaluates via base evaluator - Records MetaStep with: reified AST,
result value, trace snapshot, env snapshot

*Interception Hooks (MetaHook trait):* - `+MetaHookAction+`: Continue,
Skip, Pause, Abort - Built-in: LoggingHook, FilterHook,
DiscourseMetaHook - Stepping mode supports breakpoints and resume

*Discourse-Aware Meta-Evaluation:* - DiscourseMetaHook enters/exits
discourse per step - INVARIANT 7 preserved: discourse does not leak
between steps

*Benchmarks:* 18 criterion benchmarks covering
reify/reflect/roundtrip/meta-circular/stepping/replay/hooks
