repository facts are now the chora deed (`standards_chora.deed`), contracts are

pure renames: no record changed.

== What did not move

Every A2ML file still outside this district is named, by exact path and with
its reason, in `.machine_readable/a2ml-legacy-allow.txt`. In short:

* families with no mapping spec, which wait for kyX (D313): the Debtfile,
  Mustfile and the rest of the contractile set, `CLAIMS.a2ml`,
  `rsr-criteria-v2.a2ml`, the Hypatia rules and the DYADT vectors;
* families whose mapping spec is refused or still open: META, ECOSYSTEM,
  STATE, ANCHOR, CLADE, `rsr-profile.a2ml` and the 0-AI-MANIFEST files;
* the A2ML format family under `1-formats/a2ml/`, whose grammar describes the
  files above, so it retires with the last of them;
* the scorecard corpus, whose archive surface the owner fixed at
  `.machine_readable/archive/scorecards-v1/` (ruling R5 on #837);
* canon and data with no deed home yet, such as the readiness grades and the
  session-management state templates.

== Retiring another file

Translate anything a reader still needs into a `.deed`, then delete the file
with `git rm` and remove its ledger entry in the same commit. Do not archive
it: `9-archive/` is no exemption (owner, 2026-11-13).
`scripts/check-a2ml-archived.sh` fails on an A2ML file that is not in the
ledger, archive included, and on a ledger entry whose file is gone.
The exemption ratchet fails if the ledger grows.
