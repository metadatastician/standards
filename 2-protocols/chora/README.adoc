= Chora

A chora is a deed that declares identity for a scope of the estate. There are three levels: forge, estate and repo.

* link:CHORA-SPEC.adoc[CHORA-SPEC.adoc] is the specification (A1, draft). It replaces the v0.1.0 draft that this file used to duplicate.
* link:../../docs/estate-reconciliation/README.adoc[docs/estate-reconciliation/] holds A2 to A6, which build on it: profile, generation and deviations; the single gate; the office and farm; rules and ignore files; the carve-out of this repository.

Status: draft. Nothing here is ratified.
