# Code of Conduct

This repository follows the estate code of conduct. The canonical text, with
the pledge, the standards of behaviour, enforcement and how to report a
concern, is [3-practice/CODE_OF_CONDUCT.adoc](3-practice/CODE_OF_CONDUCT.adoc).

This file exists so that GitHub's community profile finds the policy. It
deliberately holds no copy of the text, so the two cannot drift apart.
