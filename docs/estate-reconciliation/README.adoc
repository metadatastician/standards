== Reading order

A1 first. A2 to A7 each build on the ones before them and name the version they build on in their status line. A6 is the specification that moves files out of this repository.

== Conventions

* Evidence tags: `[M]` measured by the author on the date and commit stated in the evidence section; `[R]` estate record, not recounted; `[I]` inferred; `[O]` owner ruling.
* Identifiers. Every decision, law and test id is local to its specification. Outside it, write the spec first (`A3 G4`). A test runner reports a test as `<spec>/<id>` (`A3/G10`).
* Paths in a specification name files as they are at the commits listed in its evidence section. A6 moves some of them.
* The specifications create no `.a2ml` file.
* References tagged `[R: plan ...]` cite the Estate Reconciliation Plan, which is not kept in this repository. They are records of what the plan says, not links.

== Examples

`examples/` holds the sample deeds and files that the specifications quote. They carry an `.example` suffix so that CI and tooling do not read them as live files. See `examples/README.adoc` for how to lint one.

`A6-entry-rates.tsv` is the per-entry change-rate table that A6 describes. It is an output measured at commit `be39f90` and is not regenerated here.

== Status of A6 numbers

A6's figures were measured at `be39f90`. This repository has moved on since. The rates are a baseline for the first move and are to be recomputed by the A6 checker.
