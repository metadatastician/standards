# pipe-grep-q-allow.txt — SHRINK-ONLY ledger for scripts/check-pipe-grep-q.sh.
#
# Under `set -o pipefail`, a pipe into a quiet grep is unsound: grep exits at
# its first match, the writer is killed by SIGPIPE, and the pipeline reports
# 141, so a match reads as no match (a test fails at random; a gate written
# `if writer | grep -q BAD` passes wrongly). The fix is to capture, then match:
# out=$(writer); grep -q PATTERN <<<"$out".
#
# Each line names a file that still has the pattern and how many times:
# `path:count`. The gate fails if a file not listed gains one, if a count
# GROWS, or if an entry is STALE (the count fell or reached zero). Fixing a
# line means lowering or deleting its entry in the same change (`--prune` does
# that). Never add a line; never raise a count. Generated once, on 2026-11-17,
# by `bash scripts/check-pipe-grep-q.sh --print`.
