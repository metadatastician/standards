=== What Needs Proving

==== LOL Information Theory Postulates (6)

* `+information_theory.agda+` has 6 postulated axioms about entropy,
mutual information, etc.
* Audit: which are genuine mathematical axioms vs. provable lemmas?
* Entropy non-negativity and chain rule should be constructively
provable

==== A2ML Parser Proofs (closed here: format retired, sources moved out)

* *Status*: closed for this repository. A2ML is a retired format (owner
rulings D99, D269c, D312, D313; see the Machine-Readable Metadata notice
in the repository `README.adoc`). Its parser-correctness need is not
carried forward here, and this document names no successor for it.
* *Where the files are*: `+a2ml/src/A2ML/Proofs.idr+`, `+Parser.idr+`,
`+TypedCore.idr+` and `+Surface.idr+` were removed from this repository
by #680 (commit `+24a12d6f+`, 2026-08-28, "carve-out: evict a2ml, lol
and the repo-guardian pair"), which moved the a2ml tree with its history
to `hyperpolymath/a2ml` by `git subtree split`. They are at
`+src/A2ML/+` there; at that repository's `HEAD` `+a1c1df44+`
(2026-10-01) the four files are byte-identical to the versions removed
here.
* This document records no check receipts for those files. Any audit of
them belongs to `hyperpolymath/a2ml`, not to this repository's proof
needs.

are correct

==== Axel Protocol Obj.magic

* `+2-protocols/axel/src/Tea.res+` — 8+ `+Obj.magic+` calls for DOM

==== Groove Protocol Reference

* `+2-protocols/groove/reference/groove-proxy/GrooveProxy.idr+` — Idris2

=== Recommended Prover

postulates)
* *Idris2* for Avow, Groove protocol correctness (already in use). A2ML
no longer appears here: the format is retired and its proofs moved out
(see A2ML above).
