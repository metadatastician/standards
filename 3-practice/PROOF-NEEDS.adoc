== Claims

=== coordination.k9 grammar (GrammarExtension.idr)

All three are statements about the RFC 5234 language of the grammars: the
set of byte strings with a derivation.

[cols="3,1,4",options="header"]
|===
| Claim | Status | Trust boundary and correspondence

| `v11FilesAreV12Files`: if two grammars agree on every rule but `body`,
  and v1.2's `body` is v1.1's with optional elements inserted, every v1.1
  file is a v1.2 file.
| PROVEN
| Idris2 kernel and `base` (including `DecEq String`, which rests on
  primitive string equality). The concrete `body` lists are transcribed in
  the proof; `validate.js --self-test` checks on every CI run that they are
  the committed grammars' `body` rules, and that every other v1.1 rule is
  unchanged in v1.2. Those two checks are TESTED: a JavaScript comparison
  of the committed files, not itself verified.

| `deedFilenameEquiv`: the right-recursive `deed-filename` (2026-11-09)
  denotes the same strings as `1*deed-char %s".deed"`.
| PROVEN
| As above. Holds for every definition of `deed-char`.

| `altSwap`: reordering `date`'s alternatives keeps its language.
| PROVEN
| As above.

| apg-js 4.4.0 (ordered choice, greedy repetition) accepts exactly the
  grammar's language on these files.
| TESTED
| `validate.js --self-test`: the root `coordination.k9`, the examples and
  3 valid fixtures (LF and CRLF), 13 invalid fixtures, 6 mutants of the
  root file. Not proved: the two editorial rewrites of 2026-11-09 exist
  because apg-js and the RFC 5234 meaning had diverged.
|===

=== Overlay Protocol ABI (OverlayProtocol.idr)

The protocol is SPEC-ONLY with implementation deferred
(`2-protocols/overlay/DECISION.adoc`). The file typechecks, and every
function in it is total. What it establishes is narrower than its comments
suggest:

[cols="3,1,4",options="header"]
|===
| Claim | Status | Note

| `peerTypeExhaustive`, `peerTypesDistinct`, `DecEq PeerType`
| PROVEN
| Small facts about a two-constructor type.

| `conformantPreservesBase`, `conformantReversible`
| PROVEN
| Field projections of `ConformantOverlay`: they restate what a value of
  that type already carries.

| The five protocol invariants for any real overlay
| OPEN
| No implementation exists, so none is discharged. The types also need
  revision before they can carry them; see the findings below.
|===

Design findings, recorded for when the protocol is revisited (no change is
made to a deferred protocol here):

. Invariant 1 is vacuous as stated. `ConformantOverlay` asks for
  `NonModification baseState baseState`, which `Refl` inhabits for every
  state. It needs the base state before and after activation.
. `AdditiveOnly` carries its own two base states, unrelated to the
  overlay's `baseState` or `activationFn`.
. `Switchable` and `FullyIdempotent` are required at one base state only.
  `UniversallySwitchable` is defined but not used.
. `Composable` requires only equal base states, and `OverlayChain`'s
  `bIndependentOfA` is again `NonModification x x`.
. Invariant 5's comment names `ECOSYSTEM.scm`, a retired format; the
  relationship is now declared in the deed.
. Until 2026-11-09 the file sat at `src/abi/` while declaring module
  `Overlay.ABI.OverlayProtocol`, so Idris2 rejected it where it lay, and
  no workflow checked it. It now sits at its module path.

== Toolchain deviation (policy §6)

The `idris2-standards` job installs Idris2 through
https://github.com/stefan-hoeck/idris2-pack[idris2-pack], not through the
repository's Guix manifest or a container.

* *Leg:* Idris2 typechecking of both files above.
* *Tool and version:* Idris2 from pack's package collection at install
  time. The job prints `idris2 --version` and the SHA-256 of the installed
  executable into its `idris2-standards-log` artifact. The local checks of
  2026-11-09 used Idris2 0.7.0 built from tag `v0.7.0` (commit
  `27780073c8631826d846499840b3857d9b9a4fd5`; `idris2_app/idris2.so`
  SHA-256 `86224b0e397039556c778cc3d3979812e54e4a9a783896f123c93ba45422516d`).
* *Why not Guix:* `guix.scm` provides no Idris2 and the repository has no
  Containerfile. The job reuses the install the `idris2-avow` job uses.
* *State:* `open`. It closes when `guix.scm` (or a container) provides a
  pinned Idris2 and the job uses it.
