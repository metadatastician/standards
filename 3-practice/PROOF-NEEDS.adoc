= Proof status: standards
:toc: macro

The proof-status file for this repository, in the sense of
link:PROOF-POLICY.adoc[`PROOF-POLICY.adoc`] §5. It lists every proof
obligation the repository speaks about, including the ones that are open.
The Mathesis catalogue (`hyperpolymath/mathesis`,
`docs/catalogue/catalogue.adoc`) names this file as standards' status
document.

Rewritten 2026-11-09. The earlier version listed eleven paths that no
longer exist here and did not mention the one proof file that does; see
<<moved-out>>.

== Census

2 proven of 15 rows; 1 argued; 12 open. No row is `tested-only` or
`proven-with-postulates`. Both `proven` rows hold *relative to* the
`argued` row for the Idris2 library they import (PROOF-POLICY §1.1), so
neither counts as unconditionally proven.

Every row is an engineering obligation (PROOF-POLICY §1: Idris2 for
interfaces and protocol properties). Proof Witness Grades apply to theory

[[counterexample]]
=== Counterexample: a destructive overlay is "conformant"

This module typechecks against the file above with
`idris2 --check --total` (Idris2 0.7.0, same receipt). It builds a
`ConformantOverlay` whose activation discards any base state, so the model
as written does not enforce Non-Modification:

[source,idris]
----
module Witness

import Overlay.ABI.OverlayProtocol
import Data.So

%default total

wipe : ActivationFn
wipe = MkActivationFn (\_ => MkBaseState 0 0) id

empty : BaseState
empty = MkBaseState 0 0

decl : OverlayDeclaration OExtension
decl = MkOverlayDeclaration "b" "u" (FlagBased "c") "d" "x"

add : AdditiveOnly
add = MkAdditiveOnly (MkBaseState 7 7) (MkBaseState 7 7) 1

destructive : ConformantOverlay OExtension
destructive = MkConformantOverlay decl wipe empty
  (basePreserved empty)
  add
  (MkSwitchable Refl)
  (MkFullyIdempotent (MkActivationIdempotent Refl) (MkDeactivationIdempotent Refl))
  (MkValidDeclaration Oh Oh Oh)

wipes : activate Witness.wipe (MkBaseState 1 5) = MkBaseState 0 0
wipes = Refl
----

A model that discharges §2.1 would tie the base state before activation to
the base component of the state after it, for every base state, so that
`destructive` fails to typecheck. That redesign belongs to the
implementation work the decision defers.
