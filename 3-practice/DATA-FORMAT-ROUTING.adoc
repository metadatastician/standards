= Estate Data-Format Routing: kyq, ijson-jcs and kyX
Jonathan D.A. Jewell <j.d.a.jewell@open.ac.uk>
:toc:
:toc-placement: preamble

Canonical routing for which tool handles which data format across all
hyperpolymath and metadatastician repositories. This page records rulings
already made. It adds no rule of its own: each row below quotes or restates a
recorded ruling and names where it is recorded. Like `YAML-POLICY.adoc` and
`JSON-POLICY.adoc`, it says what is *in force* and what is only *planned*.

== 1. Scope

Owner clarification, 2026-10-25 (recorded in the template `CLAUDE.md`, section
"Estate-Wide Format Migration Directives"):

____
`metadatastician/kyq` handles repository gates, queries and migration for
exactly *TOML, Dhall, KYAML and I-JSON/JCS*. Preserve TOML and Dhall. YAML/YML
content migrates to KYAML; JSON variants, including NDJSON/JSONL and JSON-LD,
use the profile in `hyperpolymath/ijson-jcs` through kyq. That name means the
owner's actual repository, which must track standards through tested update
proposals. Preserve framing, consumer filenames and JSON-LD semantics. Wider
projection belongs to *kyX*, not extra kyq formats. DEED, K9 and coordination
retain their own grammars/contracts.
____

== 3. Not in scope

* Any format outside the four families is not kyq's: wider projection belongs to
  kyX (D309, D313, D334).
* DEED, K9 and coordination files keep their own grammars and validators
  (`1-formats/deed/`, `1-formats/k9/`, `2-protocols/k9-coordination/`). The four
  data formats do not replace them.
* Launcher provisioning keeps consuming `launcher/launcher-standard_praxis.deed`.
* This page does not change the YAML or JSON rules. `YAML-POLICY.adoc` and
  `JSON-POLICY.adoc` stay authoritative for them.
* No `.a2ml` file is created or restored (D99, D269c, D312, D313).

== 4. Transitional enforcement

Planned support is not operational evidence. Until a pinned kyq executable
passes positive and negative tests for the applicable format, the explicit
transitional checks stay, and no one may claim a placeholder is a working gate
(template `CLAUDE.md`):

* YAML and KYAML: `yq` (Go version) and `scripts/kyaml-format.sh` and
  `scripts/kyaml-migrate.sh`, per `YAML-POLICY.adoc` Y-1 and §3.4. No Python
  YAML parser (D293).
* JSON and JSON Lines: `scripts/check-ijson-jcs.sh`, per `JSON-POLICY.adoc`,
  backed by `hyperpolymath/ijson-jcs`.

`hyperpolymath/ijson-jcs` must track standards through tested update
proposals (template `CLAUDE.md`).
